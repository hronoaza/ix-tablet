## Правила оновлення

1. Не змінювати опубліковану v0.1.1 заднім числом; нові факти додавати окремими версіями.
2. Не підвищувати `REPORTED_PASS` до `REPRODUCED` без фактичного повторного запуску.
3. Публікувати тільки дозволені матеріали; приватні джерела описувати метаданими без розкриття вмісту.
4. Фіксувати повний commit SHA, SHA-256 артефакту, середовище та обмеження.
5. Відокремлювати історію задуму від незалежно підтвердженої історії реалізації.
