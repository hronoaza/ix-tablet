# Evidence — картки перевірки

Цей каталог призначено для окремих карток доказів. **Жоден тест не вважається незалежно відтвореним лише через наявність картки.**

Початковий шаблон: [EVIDENCE_TEMPLATE.md](EVIDENCE_TEMPLATE.md).

Для кожного запису IX-001…IX-010 необхідно вказати першоджерело, обмеження й один зі статусів: `SOURCE_CONFIRMED`, `REPORTED_PASS`, `REPRODUCED`, `INDEPENDENTLY_VERIFIED`, `OPEN`, `SYMBOLIC`.

Не публікуйте секретів, персональних даних третіх осіб чи приватних артефактів без дозволу.
